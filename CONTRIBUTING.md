# Contributing

Use a focused branch and keep every change corpus- and evidence-backed.

1. Run `uv sync`.
2. Add query, qrel, scope, and expected abstention behavior first.
3. Preserve raw retriever scores, stable chunk IDs, and source URIs.
4. Run the complete validation gate documented in the local delivery skill.
5. Attach corpus version, query set, config, metrics, and revision to quality claims.
